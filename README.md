# Se7enStart

This is my re-implementation of the **Windows 7 Start Menu** for **KDE Plasma 6**

This project is a fork of **Windows7StartMenu4KDE** by [walterdemacedorodrigues](https://github.com/walterdemacedorodrigues): https://github.com/walterdemacedorodrigues/Windows7StartMenu4KDE

I also took several inspirations from the [Fluent-Metro](https://github.com/bonzibudd/Fluent-Metro) skin for [Open-Shell](https://github.com/Open-Shell/Open-Shell-Menu/)

## Features

* Faithful design closely matching the look and feel of Windows 7 Start Menu
* Pinning and unpinning favorites
* Working jumplists for favorites and recents
* Recently launched applications
* Searching for applications works like you would expect - you can press the Windows/Meta key, type the name of the application you want to launch and press enter
* No categories in the application list - this is intended and matches Windows behavior
